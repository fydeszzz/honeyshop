# HoneyShop

A food journaling app with gamification — log meals, earn Honeypots, decorate your shop.

## Getting Started

```bash
npm install
npm run dev
```

App will open at http://localhost:3000

## Build for Production

```bash
npm run build
npm run preview
```

## Project Structure

```
HoneyShop/
├── index.html
├── package.json
├── vite.config.js
└── src/
    ├── main.jsx       # entry point
    └── App.jsx        # full app (feastboard-v3)
```
